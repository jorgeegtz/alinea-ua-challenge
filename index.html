SECTION B | ACCOUNT STRUCTURE & OPTIMIZATION EVENTS

Account Structure and Optimization Events

Simple iOS + Android launch structure: 5-day Sign Up warmup to build initial audience signal, followed by BAU Trial Start Smart Ads CBO backed by reverse-funnel math.

Why Start Low at Sign Up, Then Scale on Trial Start

  • Protect Capital Early: We do not force all $100k on Day 1. We start lean ($500/d warmup -> $1,000/d BAU) and only scale toward the $100k cap as cohorts prove <=$48 CPT.
  • Skip Install & Day-1 Purchase: Install campaigns bring low-intent traffic. Purchase campaigns suffer from <50 events/week and the 7-day trial lag (conversions fire on Day 7-8, outside Meta's 7DC window).
  • Budget Split (85-90% Scale / 10-15% Test): Keep 85-90% of spend in proven BAU CBO and 10-15% in Creative Testing, plus run a controlled CBO vs. ABO experiment to validate spend distribution.

Reverse-Funnel Math (From $120 CAC Backward)

Using the baseline funnel rates (30% Sign Up to Trial, 40% Trial to Paid):

  • Purchase (Goal CAC): $120.00 max CAC (12% net from Sign Up).
  • Trial Start (BAU Anchor): $120 x 40% = $48.00 max CPT.
  • Sign Up (Days 1-5 Warmup): $48 x 30% = $14.40 max CPSU.
  • App Install (Tracked Only): ~$8.64-$9.22 CPI at 60-64% Install to Sign Up.

SECTION C | CREATIVE TESTING & SCALING SYSTEM

Creative Testing and Scaling System

Separate Trial Start testing campaign using 10-15% of spend, AI + Meta MCP / automated stop-loss rules, and L3/L5/L7 fatigue detection.

Separate Testing Campaign (10-15% of Spend, Opt: Trial Start)

All new creative launches in a dedicated testing campaign optimized for Trial Start ($48 target CPT), keeping BAU delivery stable.

  • Budget-to-Volume Trade-Off: At $1,000/d BAU, 10-15% testing ($700-$1,200/wk) cannot fund 50 ads at once ($14-$24/ad is under 0.5x CPT). We start with 10-15 priority videos/wk (2-3 concepts) so each ad gets real delivery, and scale toward 40-50 ads/wk as total spend grows toward $100k/mo ($2,300-$3,500/wk testing).
  • Concept Grouping: 4-6 hook variations share one Concept Ad Group so Meta routes spend to the strongest 1-2 hooks within 48h.
  • CBO vs. ABO Experiment: Run a controlled split to test if ABO gives new hooks fairer initial spend than CBO.

Automated Decision Tree (Meta Rules + AI / Meta MCP)

Gate 1: >= 2,000 Impressions | Early Hook Check

Rule: Hook Rate (3s) < 25% AND Outbound CTR < 0.8% -> PAUSE via Meta Rule / MCP. AI tags "Weak Hook" for a 0-3s intro rewrite.

Gate 2: $48-$72 Spend (1x-1.5x CPT) | Early Intent Gate

Rule: 0 Sign Ups -> PAUSE. Patience exception: if Hook Rate > 35% and Hold Rate > 15%, allow up to 2x CPT ($96) before cutting.

Gate 3: $96-$120 Spend (2x-2.5x CPT) | Hard Stop-Loss

Rule: 0 Trial Starts at $96 spend OR CPT > 2.5x ($120) -> HARD KILL via Meta Automated Rule / MCP.

Gate 4: Days 5-7 | Winner Graduation

Rule: CPT <= $48 (up to 1.2x if Day-0 Deposit >= 65% in MMP/DB) -> WINNER. Graduate via Post ID to BAU. CPT $49-$72 with strong hook -> ITERATE.

1. How Winners Graduate

We pull the winning Meta Post ID and duplicate it into the BAU Trial Start Smart Ads CBO without editing the ad, preserving social proof and avoiding a Learning reset.

2. How We Scale Winners

Vertical: Increase BAU CBO budget by +20% every 72h only if Cost per Trial holds <= $48 and Day-0 Deposit >= 65%.
Horizontal: Every winner triggers 3-5 new 0-3s opening hooks and creator variations.

3. Creative Fatigue (L3 / L5 / L7 Trend)

Trigger: Monitor rolling L3, L5, and L7 CPT trends alongside CPC. If CPT trends upward across L3/L5/L7 AND the ad's CPC is above the account average, pause the fatigued Post ID via Meta MCP / Automated Rules and rotate in pre-tested hook variants.

SECTION D | MEASUREMENT & 90-DAY FORECAST MODEL

Measurement: Automated 90D Forecast & Holistic Attribution

How we project today's CAC during the 7-day trial lag using a 90-day rolling CVR model, trial churn, and first-renewal LTV across MMP + Meta.

Why We Forecast Instead of Waiting 7 Days: With a 7-day free trial, Week 1-2 cash purchases in Meta Ads Manager are near zero. Waiting 8 days to judge CAC slows optimization and risks overspending. Instead, we run an automated daily forecast model on today's Trial Starts.

Automated 90D Rolling Forecast Model

Every day, we pull the last 90 days of Trial Starts and Paid Subs from our MMP to calculate a rolling daily Trial-to-Paid CVR%, then apply it to today's live Meta spend and trials:

Projected Paid Subs = Today's Trials x 90D Trial-to-Paid CVR% x Churn Adj.
Projected CAC = Today's Spend / Projected Paid Subs
  • Step 1 (90D Rolling CVR%): Daily baseline from MMP (40% Trial-to-Paid in our scenario) gives a real-time conversion benchmark across iOS and Android.
  • Step 2 (Trial Churn / Cancel Rate): Factor in early trial cancellations (users who cancel before Day 7) so today's Projected CAC reflects real retention, not raw trial volume.
  • Step 3 (First-Renewal LTV Extension): The same model tracks first-renewal retention to project campaign-level LTV, ensuring we scale campaigns that retain past Month/Year 1.
